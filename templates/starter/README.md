# My Video

This project was generated by `autovideo init`.

## Quick Start

### 1. Add your reference voice

Place a reference voice file (`B00.wav`) in the **same directory as `meta.md`**:

```
B00.wav   ← 10–30 seconds of clear speech, WAV format
```

This file is required for TTS (text-to-speech) voice cloning. All narration blocks will use this voice.

### 2. Set your API key

```bash
export ANTHROPIC_API_KEY="sk-ant-..."
```

This is needed for Claude to generate visual components.

### 3. Check your environment

```bash
autovideo doctor
```

This verifies that all dependencies (Node.js, ffmpeg, Chromium, VoxCPM2, etc.) are available.

### 4. Build the video

```bash
autovideo build project.json
```

Output will be in `build/my-video/output/final_normalized.mp4`.

## Customization

- **Edit `script.md`**: Add or modify content blocks with `--- visual ---` and `--- narration ---` sections.
- **Edit `meta.md`**: Change title, aspect ratio, theme, or FPS.
- **Replace `hero.png`**: Swap in your own image. Reference it in visual descriptions as `./hero.png`.
- **Edit `autovideo.config.json`**: Adjust TTS, rendering, and caching settings.

## Directory Structure

```
├── project.json              # Entry point
├── meta.md                   # Global settings (title, aspect, theme, fps)
├── B00.wav                   # Reference voice (you provide this)
├── script.md                 # Content blocks
├── hero.png                  # Example image asset
├── autovideo.config.json     # Optional configuration overrides
└── README.md                 # This file
```
