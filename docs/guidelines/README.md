# 视频脚本制作 · 唯一入口

> **用 LLM 制作 AutoVideo 视频脚本资源（`meta.md` / `visuals.md` / `narration.md`），只需要这一个文件夹。**
> 整个目录交给 LLM（或让 agent 读本目录），不必再引用仓库里其他文档。构建视频是下一步的事，见 `../BUILD.md`（不属于本文件夹）。

## 流水线

1. **动笔前** → `process-fact-baseline.md`：把脚本要用的每个数字、行数、命令核实进事实表，写稿只准引用表内事实。
2. **写稿** → 三份写作主法**按症状选一份**（只选一份，见上表）。
3. **写稿后** → `process-dual-review.md`：学员 + 专家双角色评审，必改项清零才放行（代码精讲类必过，其余可裁剪）。
4. **交构建前** → `process-av-acceptance.md`：时长算账、视觉模式核对、逐项验收清单；构建后抽帧验收。

格式规范（`AUTHORING.md`）与通用底线（`baseline.md`）贯穿四步，始终有效。

## 用法约定

- 方法/工序文档末尾都有「给 LLM 的提示词模板」一节：填空后发令即可。
- 系列事实表全系列共用一张，存系列公共位置（如 `<系列公共目录>/facts.md`）；契约存 `plan.md`（全系列一份）；其余写作中间产物存脚本同目录，不进 `project.json`、不参与编译。
- 验收两道并过：`process-av-acceptance.md` 步骤 3 的通用清单 + 本系列自己的清单副本（系列目录下 `acceptance-checklist.md`，按该文步骤 5 回写维护）；术语首现表存各集目录（`term-table.md`，与契约 `plan.md` 并列维护），验收时对照旁白逐行回查。
- 「通用底线」已单文件化为 `baseline.md`（2026-08-30 起不再在五份文档中重复维护，原 `check-baseline.sh` 同步脚本已删除）；改底线只改 `baseline.md`。
