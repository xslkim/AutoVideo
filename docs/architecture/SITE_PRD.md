# 作品集站点 PRD — 可深读的技术视频站

> 基于 `project/` 下 35 个视频项目(501 章节讲解、约 4.6 小时)构建个人作品集网站。
> 本文档是 **产品需求规格**,定义"做什么"与"体验如何",不涉及技术实现。

---

## 1. 产品定位

**一句话**:视频是入口,图文同步深读是主体 —— 让硬核技术内容真正能被学会,而不仅仅是看完。

**性质**:个人作品集站点(面向招聘方 / 同行 / 技术学习者),不是自媒体增长平台。

**核心差异点**(数据天然支撑,竞品做不到):
1. **逐句同步**:视频播放与讲稿逐句高亮联动,点文字跳视频、视频播到哪文字滚到哪。
2. **章级深读**:每个视频章节(block)可挂载远超视频时长的深度讲解(推导 / 代码 / 公式 / 易错点)。
3. **精准分享**:每句话一个链接锚点,可定位到"视频第几分几秒的第几句"。

**与现有 `web/` 的关系**:`web/` 是给作者自己用的「视频制作管理工具」(剪片编辑器),本站是面向观众的「成品展示站」,二者独立。

## 2. 用户与场景

### 2.1 主要用户

| 用户 | 画像 | 核心诉求 | 典型场景 |
|---|---|---|---|
| 招聘方 / 面试官 | 评估作者技术深度 | 快速判断专业度,找到代表作 | 浏览项目卡墙,点进代表作,快速扫读深读区 |
| 技术同行 / 学习者 | 图形学 / 算法 / 仿真方向 | 不只看懂"是什么",要懂"为什么",能反复啃难点 | 看视频遇到不懂,切深读区看推导和代码;精准分享某句给同事 |
| 作者本人 | 作品集维护者 | 改 project 后站点自动联动;轻松补深讲 | 重渲染视频后,站点自动更新,只在 CMS 补/改深讲 |

### 2.2 核心用户旅程(同行学习者)

```
首页项目卡墙
  → 按主题(图形学/自动驾驶/AI/音视频)找感兴趣的项目
    → 点进项目详情页
      → 左看视频,右侧讲稿随播放逐句高亮
        → 某句不懂 → 点「深读」展开该 block 的推导/代码
          → 点术语加粗词 → 弹释义卡
            → 切 🌐 英文阅读模式
              → 分享当前这句话的链接给朋友
```

## 3. 功能规格

### 3.1 首页(项目卡墙)

**目的**:30 秒内让人找到代表作,传达作者技术广度。

- 顶部:个人简介(一句话定位)+ 技术栈标签(图形学 / 自动驾驶仿真 / AI / 音视频)
- 主体:项目卡片墙,按主题分组
  - 卡片信息:封面图(hero.png)、标题(中/英)、时长、章节数、主题标签、系列归属
  - 卡片可标记「代表作 / 精选」,置顶展示
- 支持按主题筛选、按时间/时长排序

### 3.2 项目详情页 ⭐(核心页面)

三栏心智,左右联动:

```
┌────────────────────┬───────────────────────────┐
│   视频播放器        │   同步讲稿区               │
│   + 章节书签        │   (逐句高亮、随播滚动)     │
│   (501 block 断点)  │   + 「深读」展开按钮        │
│                    │   + 术语加粗               │
│                    │   + 🌐 中英切换            │
└────────────────────┴───────────────────────────┘
```

**视频区**:
- 播放器 + 进度条
- 章节书签:每个 block 作为断点,点击跳转
- 当前播放章节高亮

**讲稿区**:
- 按 block 分组的旁白全文
- **逐句同步高亮**:当前播放的句子高亮,讲稿区自动滚动跟随
- **反向跳转**:点任意句子 → 视频跳到该句对应时间(精确到句)
- 关键词加粗(来自 narrations 的 highlights),悬停弹释义卡
- 每个 block 一个「📖 深读」按钮 → 展开该 block 的扩展内容
- 🌐 全站中/英切换

**深读展开区**(block 级,可空):
- 深度正文(Markdown):推导、原理补充、扩展解释
- 代码块(带语言高亮)
- 公式(KaTeX 渲染)
- 补充图(可放大查看)
- 易错点 / 注意事项
- 参考链接

### 3.3 系列聚合

- 多集项目(如 smallpt 4 集、Carla 7 集)聚合为系列
- 系列页:集数列表 + 当前集高亮 + 上一集/下一集导航
- 系列总览说明

### 3.4 全站搜索

- 跨 501 章节的标题 + 旁白全文 + 深讲扩展搜索
- 结果定位到具体项目 / 章节 / 句子

### 3.5 分享

- 每个句子可生成定位链接(含时间锚点),他人打开直达那句
- 项目级、系列级均可分享

### 3.6 CMS 编辑后台(作者用)

- 管理深讲扩展(block 级):Markdown 正文 / 代码 / 公式 / 图 / 参考链接
- 管理翻译:中英标题、摘要、扩展正文
- 管理项目元信息:主题标签、系列归属、代表作标记、封面、排序
- **联动看板**:显示 project 与站点内容的差异(见 §5)
- 编辑即写文件,版本化保留历史

## 4. 数据模型(产品视角的内容结构)

```
站点
└─ Project(35)
   ├─ 元信息(authored,可编辑)
   │   ├─ slug, 标题(zh/en), 摘要(zh/en)
   │   ├─ 主题标签[], 系列归属, 系列内序号, 是否代表作
   │   └─ 封面, 排序权重
   │
   ├─ 同步数据(synced,从 project/ 自动同步,只读)
   │   ├─ 视频文件, 总时长
   │   └─ blocks[]: id, 标题, 章节图, 旁白句[], 句子时间戳, 关键词
   │
   └─ blocks[].Extension(authored,可编辑,可空)
       ├─ 深讲正文(zh/en Markdown)
       ├─ 代码块[](语言 + 内容)
       ├─ 公式[], 补充图[]
       ├─ 术语释义[](术语 → 中英释义,服务于全站加粗词联动)
       └─ 参考链接[]
```

**关键关系**:Extension 通过 blockId 挂到对应 block 上;同一个 Extension 含中英两套。

## 5. project 联动规则(drift)⭐

**背景**:`project/` 随时会被重新 build,`script.json` 会被覆盖式更新;而深讲扩展是作者手写的心血,绝不能因 rebuild 丢失。

**核心原则**:**两层数据分离 —— synced 层可随时重建,authored 层永不被管线触碰。**

### 5.1 联动行为(产品视角)

| 场景 | synced(自动) | authored(手写) | 站点表现 |
|---|---|---|---|
| 视频新增 block B18 | 出现 | 无扩展 | 正常显示(视频+旁白),CMS 标记「⚠️ 待补深讲」 |
| 视频删除 block B05 | 消失 | 有扩展 | CMS 标记「🗑️ 孤儿扩展」,**绝不自动删**,作者决定归档/迁移 |
| block 重排(B05↔B06) | id 变化 | 对不上 | 用标题做二次匹配提示重连;MVP 仅警告 |

### 5.2 稳定标识

- 每个扩展同时记录:`blockId` + `标题` + 内容指纹
- id 漂移时用标题兜底重连,避免重排丢内容

### 5.3 联动看板(CMS 内)

作者每次同步 project 后,看板展示:
- ✅ 已匹配并更新的 block 数
- ⚠️ 新增待补深讲的 block 列表
- 🗑️ 孤儿扩展列表(对应的视频 block 已不存在)
- 🔀 id 漂移需确认的 block 列表

作者逐条处理即可。

## 6. 中英双语

**策略**:中文为主,英文是"阅读模式"。视频音频保持中文(不做英文配音)。

- 🌐 切换 → 旁白 / 深讲 / 标题 / 摘要 全切英文,视频不变
- 翻译字段可空,**留空回退中文**(不强制全译)
- 英译可先用 AI 出草稿,作者在 CMS 校对
- 术语释义维护中英两套,统一服务于加粗词联动

---

## 7. 逐句同步交互规格(产品行为定义)

**正向(视频 → 文字)**:
- 视频播放时,当前句子高亮(强调色)
- 讲稿区自动平滑滚动,保持当前句在视口舒适位置
- 当前 block 标题区也高亮,提示"在第几章"

**反向(文字 → 视频)**:
- 点击任意旁白句 → 视频跳到该句开始时间,从那句开始播放
- 点击章节书签 → 视频跳到该 block 开始

**暂停时**:高亮停在当前句,不跳动

**深读展开时**:该 block 的扩展内容出现在讲稿下方/侧边,视频继续播放不受影响

## 8. MVP 范围与验收

### P0(必须,验证核心价值)
1. **数据联动机制**:两层模型 + 同步脚本 + drift 报告(风险最高,先做)
2. **项目卡墙**:主题分组 + 卡片展示
3. **项目详情页**:视频 + 逐句同步讲稿 + 章节书签 + 🌐 切换
4. **block 深读**:至少为代表作的若干 block 填写并渲染深讲(推导/代码/公式)
5. **CMS**:编辑深讲扩展 + 翻译

**P0 验收标准**:
- 改 project 后跑同步,站点内容更新且深讲扩展不丢
- 视频播放时讲稿逐句高亮滚动;点句跳视频
- 中英切换正常;深读区代码/公式正确渲染

### P1(增强)
6. 系列聚合页 + 前后篇导航
7. 全站搜索
8. 精准分享(句级锚点链接)
9. 联动看板的孤儿/漂移处理 UI

### P2(锦上添花)
10. 深读图可缩放、可运行代码 demo
11. 系列学习进度(本地,无账号)
12. 阅读进度记忆(localStorage)
